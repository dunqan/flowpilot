# FlowPilot — vision

**Stay aware of everything that matters without having to focus on everything at once.**

FlowPilot is a Markdown-native, local-first work and attention orchestration system for one person running several concurrent projects and personal commitments. It reads and writes the Markdown files the user already owns (Obsidian vaults or plain folders), shows one portfolio-wide picture across them, and lets the user pick what to do next with an authentic **Final Version Perfected (FVP)** selection session restricted to the current context (Work, Personal, Mixed, custom). Like FVP itself, it needs **no maintenance rituals**. The list is the inbox, items are clarified when they come up in a pass, and "review" means reading a summary rather than holding a session. Optional weekly outcomes give direction without becoming a ranking. A few GTD words (next action, waiting, someday) serve as item states. Summaries, made richer by optional AI later, surface neglected work and make suggestions, but never decide.

## Product principles

1. **Markdown remains primary** — files stay readable, editable and useful without FlowPilot or Obsidian.
2. **FVP remains human-directed** — AI never silently replaces the user's comparisons with a priority score.
3. **One overview, multiple contexts** — many sources, one portfolio; context controls eligibility, not visibility.
4. **Switching is legitimate** — interleaving projects is supported; only unproductive fragmentation is flagged.
5. **Visibility is not obligation** — intentional pauses are respected.
6. **No maintenance rituals.** There is no inbox to process and no weekly review to hold; capture goes onto the list, and summaries replace reviews.
7. **AI advises; the user decides** — suggestions carry evidence and need approval before any write.
8. **Local-first and durable** — essential features work without AI or a cloud service.

## Three primary surfaces

The surfaces are provisional; [[M0]] is where the experience gets designed.

- **God's-eye overview** — portfolio situation awareness with drill-down.
- **Weekly outcomes and summaries** — optional outcomes and on-demand progress evidence, never a review step.
- **FVP workspace** — faithful, low-friction selection across eligible tasks from many projects.
