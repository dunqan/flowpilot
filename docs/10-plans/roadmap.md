# Roadmap

Milestones are named after outcomes; a human signs off each gate with evidence. Only the active milestone is detailed.

| Milestone | Outcome | Status |
|---|---|---|
| [[M0]] | Experience definition: a signed-off picture of how using FlowPilot feels, tested against example tasks with designs and throwaway POCs. No product code. | active |
| [[M1]] | Cross-project FVP over the user's own Markdown: two sources, one portfolio, safe sync, resumable context-aware sessions, optional weekly outcomes, a deterministic summary, no maintenance rituals | planned |
| M2 (sketch) | AI as attention assistant: richer summaries (replacing any review ritual), missing-next-action and neglect detection, evidence-linked Q&A. Opt-in and permission-controlled. | idea |
| Later | Other clients (CLI, Obsidian plugin, agent API), remote access and packaging | idea |

Source of the boundaries: [[flowpilot-concept]] §9 (MVP) and §11 (success criteria).
