# Lessons — records

One file per lesson, `<rule-as-slug>.md`, from `docs/templates/lesson.md`, with `areas:` naming the system pages it applies to. Indexed in `docs/lessons.md`; linked from those pages' **Gotchas**.

- `inbox/` — proposals (`<YYYY-MM-DD>-<slug>.md`) written by `code-review` and `session-wrapup`. `weekly-review` presents them; the human accepts, merges or rejects each one.
- Record a pitfall only after an agent actually made the mistake. A lesson that applies everywhere is a rule and belongs in `AGENTS.md`; a rule broken twice belongs in a script or CI.
